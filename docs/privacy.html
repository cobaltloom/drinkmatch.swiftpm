プライバシーポリシー利用規約

プライバシーポリシー

「CrewBoard」(以下「本アプリ」)は、個人開発者(以下「開発者」)が運営しています。 本ポリシーは、本アプリ(iOS版・Android版)の利用にあたり取得する利用者情報の取り扱いについて説明するものです。開発者への連絡先は、本ポリシー末尾の「お問い合わせ」をご覧ください。

取得する情報

本アプリのアカウント登録・利用にあたり、以下の情報を取得します。

  • ログイン情報(iOS版は「Appleでサインイン」、Android版は「Googleでサインイン」を利用します。各サービスから提供されるユーザー識別子およびメールアドレスを取得します。本アプリがパスワードを取得・保存することはありません)
  • お名前
  • 職種・所属会社・拠点空港
  • 生まれ年(任意。年齢が近い人を探す機能のためにのみ使用します)
  • スケジュール情報(ステイ先空港・空き時間)
  • 連絡先(任意。LINE ID・電話番号など、利用者がプロフィールに登録したもの)
  • 本人確認情報(会社メールアドレス、または確認済みユーザーが発行した確認コード)
  • プッシュ通知用のデバイストークン(通知を受け取るため。通知を許可しない場合も端末から取得されることがあります)
  • アプリ内課金の購入・利用状況(iOS版のみ。Android版にアプリ内課金はありません)
  • 通報・ブロックに関する記録(安全な利用環境を維持するため)

利用目的

  • 知り合い・新しい人とのマッチング機能の提供
  • 本人確認による安全性の確保(見ず知らずのユーザーと会う機能のため)
  • 誘い・マッチ成立などのお知らせのプッシュ通知
  • アプリ内課金の購入処理・利用状況の管理(iOS版)
  • 不正利用防止・通報対応
  • 本アプリの維持・改善

第三者への提供・委託

本アプリは以下のサービスを利用してデータを保管・処理しています。これらの事業者には、サービス提供に必要な範囲でデータへのアクセスが生じます。

  • Supabase(データベース・認証基盤)
  • Apple(Appleでサインイン、App Store / StoreKitによるアプリ内課金、プッシュ通知の配信。iOS版)
  • Google(Googleでサインイン、Firebase Cloud Messagingによるプッシュ通知の配信。Android版)

上記以外の第三者への個人情報の販売・提供は行いません。

他の利用者への公開範囲

  • 「知り合い」機能: フルネーム、職種、会社、拠点空港、スケジュールが表示されます。
  • 連絡先: マッチが成立した相手にのみ表示されます。誘いを送っただけの段階では表示されません。
  • 「新しい人を探す」機能: フルネームは表示されず、イニシャルまたは任意のニックネームのみが表示されます。生まれ年は年齢差フィルターの計算にのみ使用され、生年そのものは相手に表示されません。

データの保存期間・アカウントの削除

取得した情報は、アカウントが存在する間保存します。アカウントは、アプリ内のプロフィール画面にある「アカウントを削除」からいつでも削除できます。削除すると、プロフィール・連絡先・スケジュール・マッチング履歴・グループ・プッシュ通知用トークン等の関連データは速やかに削除されます。

アプリを利用できない場合は、ご登録のメールアドレスから下記「お問い合わせ」のメールアドレス宛てに、件名を「アカウント削除依頼」としてご連絡ください。本人確認のうえ、原則として30日以内に削除します。
